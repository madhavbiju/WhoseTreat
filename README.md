# WhoseTreat? 🍰

A mobile-first web application for couples to track shared expenses using React, TypeScript, Tailwind CSS, and Firebase. 

Instead of tracking rigid 50/50 split debts, **WhoseTreat?** embraces an **alternating expense philosophy**: if one person pays today, the other pays tomorrow. The application focuses purely on *who spent more overall* and *whose turn it is to treat next*.

---

## 🔮 Core Philosophy & Hybrid Architecture

1. **Lifetime Alternating Balance**: The app calculates a running, lifetime `balanceScore` based on the total difference in spending (`Sum of Him spent - Sum of Her spent`). This balance carries over continuously across month boundaries so that no treats or turns are ever lost.
2. **Monthly History & Stats**: While the central turn indicator reflects your lifetime standing, the **History page** dynamically filters transaction feeds and summary spend cards (`His Spend`, `Her Spend`, `Combined`) strictly to the **current calendar month**—providing a clean monthly contextual view (e.g. *June Spend*).

---

## ✨ Features

- **Dynamic Turn Indicator Card**: A card that shifts gradients and copy dynamically based on the balance:
  - **Perfectly Even**: Mint pastel gradient (*"You are perfectly even! 💚"*).
  - **He Spent More**: Rose pastel gradient (*"Her turn to treat! 🍰 He spent ₹X more overall."*).
  - **She Spent More**: Sky-blue pastel gradient (*"His turn to treat! ☕ She spent ₹X more overall."*).
- **5-Second Quick-Log Form**: Centered numeric amount input (auto-focused on load), optional descriptions, and large interactive toggle controls (`[Him]` / `[Her]`).
- **Interactive Monthly Feed**: Clean, scrollable lists representing transactions for the current calendar month, complete with custom payer badges and a delete button for accidental logs.

---

## 🛠️ Technical Stack & Schema

- **Core**: React 18, TypeScript, Tailwind CSS, Lucide React (iconography).
- **Backend**: Firebase (Firestore Database).

### Firestore Schema
The application syncs with a flat Firestore collection named **`shared_expenses`** with the following document structure:
```typescript
interface Expense {
  id: string;        // Auto-generated by Firestore
  amount: number;    // Numeric expense amount
  description: string; // Optional description (e.g. "Dinner", "Coffee")
  paidBy: 'me' | 'her'; // Payer reference ('me' maps to Him, 'her' to Her in UI)
  createdAt: Timestamp; // Firestore Server Timestamp
}
```

## 🚀 Getting Started

### 1. Install Dependencies
Clone the repository and install all packages (including `lucide-react`):
```bash
npm install
```

### 2. Configure Firebase Credentials
Open [src/config/firebase.ts] and add your project configurations:
```typescript
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT.firebasestorage.app",
  messagingSenderId: "YOUR_SENDER_ID",
  appId: "YOUR_APP_ID"
};
```

### 3. Run Locally
You can start the local development server using either of the following commands:
```bash
npm start
# OR
npm run dev
```

### 4. Build Production Bundle
To compile and optimize your assets for Firebase hosting or static deployment, run:
```bash
npm run build
```
